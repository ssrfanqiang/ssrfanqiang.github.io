一、初识小火箭：不仅仅是“工具”，更是网络自由的钥匙

如果你认为小火箭仅仅是一个“VPN软件”，那你就大错特错了。它本质上是一个基于规则的高性能代理客户端，这意味着它并不像传统VPN那样将所有流量粗暴地导入隧道，而是通过精细的分流逻辑，让你在国内应用与海外服务之间无缝切换。其核心价值在于：

  • 极致的灵活性：支持vmess、vless、Shadowsocks、Trojan乃至WireGuard等多种主流协议，几乎覆盖了所有主流代理服务器的需求。
  • 细腻的规则引擎：你可以自定义哪些域名或IP走代理，哪些直连，实现“国内秒开，国外流畅”的完美体验。
  • 透明的网络监控：实时显示当前连接的延迟、上行/下行速率以及总流量消耗，让你对每一兆流量都了如指掌。
  • 优雅的交互设计：深色模式、手势操作、Widget小组件，每一个细节都彰显着为苹果用户量身定制的匠心。

三、核心配置实战：手把手教你添加vmess节点

vmess协议是V2Ray项目中最经典的传输协议，它通过UUID（用户唯一标识）来验证身份，并支持多种加密与传输方式。在小火箭中配置vmess节点，流程并不复杂，但每个字段都值得你仔细核对。

步骤一：获取服务器信息

你需要从你的服务商（或自建服务器）处获得以下六项核心参数： - 地址（Address） ：服务器的IP地址或域名。 - 端口（Port） ：通常为443、8443或8080等。 - UUID（用户ID） ：一串形如“9b6d7e3f-1a2b-3c4d-5e6f-7a8b9c0d1e2f”的字符串。 - 额外ID（AlterId） ：旧版协议中常用，现在多为0。 - 加密方式（Security） ：通常为“auto”或“chacha20-poly1305”、“aes-128-gcm”。 - 传输协议（Network） ：常见的有tcp、ws（WebSocket）、grpc等。

步骤二：在小火箭中手动添加

  1. 打开小火箭，点击首页右上角的 “+” 号。
  2. 在类型（Type）一栏，选择 “Vmess”。
  3. 在弹出的界面中，你会看到：
    • 名称（Remark） ：随意填写，便于识别，如“香港-01”。
    • 地址（Address） ：填入服务器IP或域名。
    • 端口（Port） ：填入端口号。
    • UUID：粘贴你的用户ID。
    • 额外ID（AlterId） ：按需填写（通常为0）。
    • 加密（Cipher） ：选择与服务器一致的加密方式。
  4. 关键进阶设置：点击下方的 “传输” 选项。如果你使用的是ws（WebSocket） 协议，需要在这里填写 “路径（Path）” 和 “Host” （通常为你的伪装域名）。如果你使用的是grpc，则需要填写 “ServiceName” 。
  5. 点击右上角 “保存”。

步骤三：通过二维码导入（懒人福音）

如果你的服务商提供二维码配置，那么无需手动输入。在小火箭首页，点击右上角的 “扫描” 图标，直接扫描二维码即可自动填充所有信息。这是最快捷、最不易出错的方式。

四、连接与优化：从“能连上”到“飞一般的体验”

配置完成后，点击首页的节点卡片，然后打开右上角的 “连接”开关。此时，系统会提示添加VPN配置，点击允许并输入你的锁屏密码即可。

成功连接后，状态栏会出现VPN图标。但这仅仅是开始，想要获得更流畅的体验，你需要进行以下优化：

1. 启用“全局路由”与“分流规则”

小火箭的最大魅力在于分流。默认情况下，它会将国内流量直连，国外流量走代理。你可以在“设置-路由”中，选择不同的策略： - 配置：使用默认的“仅代理国外”规则。 - 全局代理：所有流量均通过代理（不推荐，会拖慢国内访问速度）。 - 直连：关闭代理，仅作为网络监视器使用。

2. 调整“延迟测试”与“节点选择”

在主界面的节点列表中，每个节点右侧会有一个数字，那是延迟值。点击右上角的 “闪电”图标，可以批量测试所有节点的延迟。建议选择延迟低于200ms且丢包率低的节点。对于游戏或视频会议，建议选择延迟更低的节点。

3. 利用“脚本”实现去广告与解锁

小火箭支持运行JavaScript脚本，这意味着你可以通过加载特定脚本，实现去除Safari浏览器广告、解锁部分视频网站区域限制等功能。在“设置-脚本”中，你可以添加远程脚本URL或本地新建脚本。例如，著名的“广告净化”脚本，能极大改善浏览体验。

4. 管理“证书”与“TLS指纹”

如果你遇到连接不稳定或无法访问的情况，可以尝试在节点设置中，将“TLS”选项的“指纹”从“默认”改为“随机”。这有助于规避某些基于TLS特征检测的防火墙。

五、常见问题深度剖析：解决你的“疑难杂症”

在实际使用中，用户总会遇到各种奇怪的问题。以下是基于大量用户反馈整理的常见问题及解决方案：

Q1：节点配置无误，但就是连不上，怎么办？

  • 检查时间：vmess协议对时间敏感，请确保手机系统时间与网络时间同步（设置-通用-日期与时间，开启自动设置）。
  • 检查端口与UUID：重新复制粘贴，注意不要有多余空格。
  • 更换传输协议：如果服务器支持，尝试将TCP改为WS，或反之。

Q2：连接成功，但速度极慢，网页打不开？

  • 更换节点：可能是当前节点负载过高，尝试切换到其他地区节点。
  • 关闭“全局代理”：确认路由设置为“配置”或“仅代理国外”。
  • 检查手机信号：Wi-Fi与蜂窝数据切换测试。

Q3：小火箭耗电严重吗？

  • 小火箭在后台运行时，会保持网络长连接，耗电相对较高。建议在“设置-通用-后台App刷新”中，允许小火箭在特定网络（如Wi-Fi）下运行。

Q4：如何更新vmess节点信息？

  • 如果使用订阅链接，只需复制新的订阅地址，在小火箭首页点击右上角“+”旁边的小圆圈图标（订阅），粘贴链接并保存，然后点击“下载”即可自动更新所有节点。

FAQ

Shadowrocket 支持哪几种代理协议？
Shadowrocket 支持多种协议，包括 Shadowsocks、Vmess、VLess、Trojan、HTTP、SOCKS5 等。它还可解析部分 QuantumultX 与 Clash 的订阅格式，适合 iOS 用户进行全协议代理管理与切换。
Trojan 的伪装域名如何选择更安全？
伪装域名应选择真实可访问的网站，且证书有效。这样 Trojan 流量能伪装成正常 HTTPS 请求，减少被封锁或检测的风险，提高节点安全性和稳定性。
Nekoray 的配置文件在哪里保存？
Nekoray 的配置文件默认保存在程序目录下的 `config.json` 中。用户可手动备份此文件以迁移配置，也可使用导入导出功能在不同设备间同步节点数据。
WinXray 延迟检测功能如何提高网络体验？
WinXray 会定期检测节点延迟，结合策略组自动切换到低延迟节点。保证网页、视频和游戏流量通过最佳节点，提高访问速度和连接稳定性，减少掉线和卡顿。
SSR 的混淆插件有什么作用？
混淆插件用于伪装流量，使其看起来像普通的 HTTP 或 TLS 请求。常见类型有 plain、tls1.2_ticket_auth 等。合理设置混淆能有效降低被识别的风险，提升连接成功率。
V2Ray 如何通过策略组优化访问速度？
策略组允许用户将节点按延迟、地域或用途分组。结合路由规则，V2Ray 会自动选择最优节点处理流量，提升访问速度并降低延迟，尤其在访问海外网站时效果明显。
Clash 的节点健康检测如何工作？
Clash 会定期对每个节点进行延迟和丢包率测试，并根据结果标记节点健康状态。结合策略组，可以自动切换到最优节点，避免访问高延迟或失效节点，提高整体网络稳定性和效率。
QuantumultX 的 MITM 功能如何使用？
QuantumultX 的 MITM（中间人）功能可拦截 HTTPS 流量，用于修改或分析请求与响应。开启时需安装客户端生成的根证书，确保能正确解析加密数据。
如何在 Clash for Android 中导入订阅链接？
Clash for Android 支持通过订阅链接快速导入节点。用户只需在配置界面中点击“新建配置”，选择“URL 导入”并粘贴订阅地址即可，程序会自动下载并解析所有节点配置。
V2Ray 中的 alterId 是什么，现在还有必要配置吗？
alterId 曾用于 VMess 的用户混淆机制以防止重放攻击，但在 V2Ray 新版本与 VLess 出现后，alterId 已不再推荐使用。现代配置多使用 UUID 或直接迁移至 VLess/XTLS 以获得更好性能与安全性。
